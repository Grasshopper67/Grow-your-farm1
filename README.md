# Garden World 3D

A playable 3D browser farming game inspired by the cozy crop-growing and progression loop of garden simulator games. This is an original project and is not affiliated with Roblox Grow a Garden.

## Publish on GitHub Pages
1. Upload `index.html` and this `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then click **Save**.
5. Open the Pages URL GitHub provides.

## Controls
- Select a seed in the Seeds shop.
- Left-click an empty soil bed to plant.
- Left-click a fully grown crop to harvest.
- Drag to rotate the camera; scroll to zoom.
- Sell harvested crops from your backpack.
- Buy gear and pets for bonuses; expand your garden.

## Features
- 3D low-poly garden, plots, trees, fence, and seed stall
- Six crop types and a seed inventory
- Crop growth, harvest values, backpack, and sell-all
- Golden and wet crop mutations
- Changing weather that affects growth
- Sprinkler, watering-can, and fertilizer upgrades
- Garden Bee and Lucky Bunny pets
- Garden expansion and browser save data

Three.js is loaded from jsDelivr, so an internet connection is required.
